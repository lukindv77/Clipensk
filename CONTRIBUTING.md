# Участие в разработке Clipensk

Clipensk является открытым исходным кодом, однако данный репозиторий используется как управляемый публичный репозиторий проекта.

На текущем этапе внешние изменения, Issues, Pull Requests и публичные обсуждения не принимаются. Право изменения канонического репозитория сохраняется за владельцем проекта и подключёнными владельцем инструментами разработки.

Публичность репозитория предоставляет право чтения, клонирования и использования исходного кода в соответствии с выбранной Open Source лицензией, но не означает автоматического права изменять данный канонический репозиторий.
