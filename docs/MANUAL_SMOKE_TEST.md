# Ручная проверка Clipensk на Windows

Список действий для ручной проверки (smoke) того, что автотесты и CI подтвердить не могут: окна,
трей, буфер обмена, права доступа к папкам, работа с реальными файлами хранилища на Windows
(`HANDOFF_CURRENT.md` §I.10). Составлен для сборки `8fabb62` (main на 2026-09-23).

Проверяйте на **тестовых данных**: Clipensk записывает всё, что попадает в буфер обмена. Пока идёт
проверка, не копируйте пароли и другие секреты, либо заблокируйте Clipensk перед этим (раздел D).

## 0. Как сообщить результат

Для каждого пункта — его номер и итог:

- **OK** — всё как в «Ожидается»;
- **FAIL** — точный текст сообщения (его можно выделить и скопировать) или снимок экрана, и что
  делали перед этим;
- **—** — пункт не выполнялся (например, нет Windows 10).

Первой строкой отчёта укажите значение «Сборка: …» со страницы «О программе» (пункт A6).

## 1. Подготовка

### 1.1. Что нужно

- Windows 11 x64. Для пункта K (предупреждение) — дополнительно Windows 10 x64, можно в
  виртуальной машине.
- Учётная запись на GitHub с доступом к репозиторию `lukindv77/Clipensk`: артефакты скачиваются
  только после входа.

### 1.2. Установить среду выполнения

Сборка не включает в себя .NET и Windows App SDK, их нужно установить один раз:

1. **.NET 10.** Откройте <https://dotnet.microsoft.com/download/dotnet/10.0>, в разделе
   «.NET Desktop Runtime 10.0.x» скачайте установщик **Windows x64** и установите.
2. **Windows App SDK 2.4.** Откройте
   <https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads>, найдите версию **2.4** и
   скачайте установщик среды выполнения (Windows App Runtime) для **x64**, установите.

Если чего-то не хватает, при запуске Windows покажет сообщение об отсутствующем компоненте —
пришлите его текст.

### 1.3. Скачать сборку

1. Войдите на GitHub и откройте прогон, в котором собрана проверяемая версия:
   <https://github.com/lukindv77/Clipensk/actions/runs/35888063344>
   («Native SQLCipher», ветка `main`, коммит `8fabb62`, статус — зелёная галочка).
2. Прокрутите страницу вниз до раздела **Artifacts**.
3. Нажмите **`clipensk-app-win-x64-unpackaged`** — скачается zip-архив. Второй артефакт,
   `clipensk-sqlcipher-win-x64`, не нужен: это только нативная библиотека и её протоколы.
4. Артефакты хранятся 14 дней — этот до **7 октября 2026**. Если ссылка на артефакт пропала,
   попросите пересобрать (или сами: вкладка **Actions** → **Native SQLCipher** → **Run workflow** →
   ветка `main` → **Run workflow**, и дождитесь зелёной галочки, около 25 минут).

### 1.4. Распаковать

1. Щёлкните скачанный zip правой кнопкой → **Свойства**. Если внизу есть флажок
   **«Разблокировать»**, отметьте его → **ОК**.
2. Создайте папку для программы, **в которую вам можно писать**, например
   `%LOCALAPPDATA%\Programs\Clipensk-test` (вставьте этот путь в адресную строку Проводника).
   Не распаковывайте в `C:\Program Files`: рядом с программой хранится `settings.json`, и из папки
   без права записи Clipensk не запустится (это проверяет пункт L).
3. Распакуйте архив в эту папку. В ней должны оказаться `Clipensk.App.exe`, `sqlcipher.dll`,
   `runtime-delivery-manifest.json` и папка `licenses`.

### 1.5. Тестовые папки

Создайте папку `%USERPROFILE%\ClipenskTest` и в ней пустые папки `Data`, `Backups` и `Moved`.
Хранилище будет в `Data`, резервные копии — в `Backups`, перенос — в `Moved`.

### 1.6. Как начать заново

Если нужно повторить проверку с нуля: иконка Clipensk в трее → правый щелчок → **«Завершить
работу»**, затем удалите `settings.json` рядом с `Clipensk.App.exe` и содержимое папок из 1.5.

## A. Первый запуск и пароль

**A1.** Запустите `Clipensk.App.exe`. Если появится «Windows защитил ваш компьютер»: **Подробнее**
→ **Выполнить в любом случае** (сборка не подписана).
*Ожидается:* окно «Первоначальная настройка», в трее — иконка Clipensk.

**A2.** Нажмите **«Выбрать каталог данных»** и выберите пустую папку `ClipenskTest\Data`.
*Ожидается:* сообщение «Каталог данных сохранён…» и экран «Создание пароля Clipensk».

**A3.** Проводник → `ClipenskTest\Data` → правый щелчок → **Свойства** → **Безопасность**.
*Ожидается:* доступ есть только у вашей учётной записи, SYSTEM и Администраторов.

**A4.** Введите пароль, повторите его, задайте подсказку → **«Создать защиту и разблокировать»**.
*Ожидается:* Clipensk разблокирован и просит задать правила сбора.

**A5.** В правилах сбора выберите базовое правило **«Разрешить»**, для форматов задайте лимиты
(или «Без лимита») → **«Сохранить первоначальные правила»**.
*Ожидается:* правила сохранены, журнал доступен.

**A6.** Откройте **«О программе»**.
*Ожидается:* «Сборка: 8fabb62…». Запишите это значение для отчёта.

## B. Сбор истории и журнал

**B1.** Скопируйте (Ctrl+C):
- текст в Блокноте;
- фрагмент веб-страницы с форматированием;
- снимок экрана (Win+Shift+S);
- два файла в Проводнике.

Откройте журнал: левый щелчок по иконке в трее.
*Ожидается:* четыре записи с правильным источником (Блокнот, браузер, инструмент снимков,
Проводник) и предпросмотром.

**B2.** Проверьте поиск по тексту, период («Начало/Конец периода» → «Показать») и фильтр по
приложению.
*Ожидается:* список сужается и возвращается обратно.

**B3.** Выберите текстовую запись → **«Скопировать в буфер обмена»** → вставьте в Блокнот.
Сделайте то же для снимка экрана (вставка в Paint) и для записи с файлами (вставка в Блокнот).
*Ожидается:*
- текст и картинка совпадают с исходными;
- для файлов вставляются их полные пути, по одному на строку;
- в журнале **не** появляются новые записи-дубликаты от этих возвратов.

**B4.** Выберите запись из браузера → **«Вставить как обычный текст»** → вставьте в WordPad или Word.
*Ожидается:* текст без форматирования.

## C. Окно, трей, горячая клавиша

**C1.** «Настройки» → «Горячая клавиша вызова журнала»: отметьте, например, Ctrl и Alt, клавиша V →
**«Применить горячую клавишу»**. Перейдите в Блокнот и нажмите Ctrl+Alt+V.
*Ожидается:* открывается журнал.

**C2.** В открытом журнале нажмите Escape; снова откройте журнал и щёлкните мимо окна.
*Ожидается:* окно скрывается, фокус возвращается в Блокнот (можно сразу печатать).

**C3.** Закройте окно крестиком. Правый щелчок по иконке в трее.
*Ожидается:* процесс работает; в меню — «Журнал», «Настройки», «Завершить работу»; пункты
работают.

**C4.** При работающем Clipensk запустите `Clipensk.App.exe` ещё раз.
*Ожидается:* сообщение «Clipensk уже запущен для этого пользователя Windows…», второй экземпляр
не появляется.

**C5.** «Настройки» → «Автозапуск» → «Запускать Clipensk при входе в Windows» → **«Сохранить
автозапуск»**. Выйдите из Windows и войдите снова. Затем выключите автозапуск и повторите.
*Ожидается:* после входа Clipensk в трее; после выключения — нет.

## D. Блокировка

**D1.** «Настройки» → **«Заблокировать сейчас»**. Скопируйте текст «при блокировке». Разблокируйте.
*Ожидается:* журнал был недоступен; записи «при блокировке» в журнале нет.

**D2.** Заблокируйте и введите неверный пароль.
*Ожидается:* «Пароль неверен. Clipensk остаётся заблокированным.», подсказка видна.

**D3.** «Автоматически блокировать при простое», 1 минута → «Сохранить параметры блокировки».
Ничего не делайте 1–2 минуты.
*Ожидается:* Clipensk заблокирован. Затем верните автоблокировку как было.

## E. Приложения и группы

**E1.** «Приложения» → у источника со снимками экрана (или у браузера) → **«Выбрать группу…»** →
«Создать новую группу» → **«Взять имя приложения»** → в правилах запретите изображения → «Далее».
*Ожидается:* экран подтверждения с числом удаляемых записей и представлений.
Нажмите **«Удалить и перенести»**.
*Ожидается:* «Приложение перенесено в группу…»; в журнале у этого приложения больше нет
изображений.

**E2.** Журнал → фильтр по группе и «Нераспределённые приложения…».
*Ожидается:* фильтры работают, у записей видна группа.

**E3.** «Приложения» → раздел «Группы приложений»: переименуйте группу; перенесите приложение из
группы E1 в другую группу и при вопросе оставьте опустевшую группу, затем удалите её.
*Ожидается:* всё выполняется, сообщения соответствуют действию.

## F. Обслуживание

**F1.** «Обслуживание» → **«Проверить каталог»**, **«Уплотнить Current»**.
*Ожидается:* сообщения об успешной проверке и уплотнении.

**F2.** (На второй день проверки, когда в журнале есть записи за вчера.) «Настройки» →
«Автоматическая ротация архивов» → «Максимум календарных дней» = 1 → «Сохранить параметры
ротации». «Обслуживание» → **«Выполнить ротацию сейчас»**.
*Ожидается:* «Ротация завершена…»; вчерашние записи в журнале остаются, в сведениях о записи —
«Хранение: Archive: …». Если завершённых дней с записями нет — «Ни один завершённый диапазон не
достиг заданных порогов…».

## G. Перенос хранилища

**G1.** «Настройки» → «Каталог данных» → **«Перенести хранилище…»** → папка `ClipenskTest\Moved` →
подтвердите.
*Ожидается:* Clipensk блокируется, идёт прогресс; затем «Хранилище перенесено в …, прежний каталог
удалён»; папка `Data` пуста или удалена. После разблокировки прежним паролем журнал на месте.

**G2.** Перенесите хранилище обратно в `ClipenskTest\Data`. Если папка `Data` была удалена,
создайте её заново пустой.
*Ожидается:* то же, что в G1.

## H. Резервная копия и открытие хранилища из папки

**H1.** «Настройки» → **«Создать резервную копию…»** → папка `ClipenskTest\Backups`.
*Ожидается:* окно подтверждения с путями, числом файлов, объёмом и свободным местом.
Подтвердите.
*Ожидается:*
- Clipensk блокируется, идёт прогресс;
- затем «Резервная копия создана: «…\Clipensk-backup-ГГГГ-ММ-ДД_ЧЧ-ММ-СС»»;
- в `Backups` — ровно эта папка, без `.incomplete`;
- на вкладке «Безопасность» папки копии доступ только у вас, SYSTEM и Администраторов.

**H2.** Разблокируйте Clipensk и скопируйте текст «после копии».

**H3.** «Настройки» → **«Открыть хранилище из папки…»** → папка копии из H1.
*Ожидается:* окно подтверждения, что текущее хранилище остаётся на месте.
Подтвердите и разблокируйте паролем.
*Ожидается:* в журнале всё, что было до копии, и **нет** записи «после копии»; в «Настройках»
каталог данных — папка копии.

**H4.** Снова **«Открыть хранилище из папки…»** → `ClipenskTest\Data`, разблокируйте.
*Ожидается:* запись «после копии» на месте.

**H5.** Проверьте отказы — каждый должен давать понятное сообщение без изменений:

| Что выбрать | Ожидаемое сообщение |
|---|---|
| «Открыть хранилище из папки…» → текущий `ClipenskTest\Data` | «Выбран текущий каталог хранилища» |
| «Открыть…» → `ClipenskTest\Data\Current` | «…находится внутри текущего хранилища…» |
| «Открыть…» → пустая папка `ClipenskTest\Moved` | «…нет хранилища Clipensk…» |
| «Создать резервную копию…» → `ClipenskTest\Data\Current` (или сама `Data`) | «…находится внутри хранилища…» |

**H6.** Сделайте в Проводнике копию папки из H1 и переименуйте копию, добавив в конец имени
`.incomplete`. «Открыть хранилище из папки…» → эта папка.
*Ожидается:* отказ «…незавершённая резервная копия…». Затем удалите эту копию.

**H7.** (Необязательно, если хранилище большое.) Создайте резервную копию и во время прогресса
нажмите «Отмена».
*Ожидается:* «Создание резервной копии отменено, незавершённая копия удалена»; в `Backups` нет
новой папки и нет папки `.incomplete`.

## I. Смена пароля

**I1.** «Настройки» → **«Сменить пароль…»** → текущий пароль, новый пароль дважды, подсказка →
«Сменить пароль».
*Ожидается:*
- Clipensk блокируется, идёт прогресс «Перешифровано баз: N из M»;
- затем «Пароль изменён…»;
- прежний пароль больше не подходит, новый подходит, журнал на месте.

**I2.** «Открыть хранилище из папки…» → резервная копия из H1.
*Ожидается:* она открывается **прежним** паролем, новый к ней не подходит.
Вернитесь к `ClipenskTest\Data` (новый пароль).

**I3.** (Необязательно.) Начните смену пароля и во время прогресса нажмите «Отмена».
*Ожидается:* «Смена пароля отменена… Действует прежний пароль.»

**I4.** (Необязательно, проверка обрыва.) Сделайте резервную копию, откройте её через «Открыть
хранилище из папки…» и работайте с ней. Начните смену пароля, во время прогресса завершите
`Clipensk.App.exe` в Диспетчере задач (Подробности → Снять задачу) и запустите снова. Введите
прежний пароль, а если он не подходит — новый.
*Ожидается:* один из паролей открывает хранилище, записи на месте. Если прежний не подходит,
появляется сообщение, что нужен новый.

## J. Повреждения хранилища (только на копии)

Выполняйте на резервной копии, открытой через «Открыть хранилище из папки…», — не на основной
`Data`.

**J1.** Завершите работу Clipensk (трей → «Завершить работу»). В папке копии удалите
`Current\storage-catalog.db`. Запустите Clipensk и введите пароль.
*Ожидается:*
- сообщение о неполном хранилище и кнопка «Восстановить storage-catalog.db»;
- после восстановления: «storage-catalog.db восстановлен…»;
- после разблокировки журнал на месте.

**J2.** Завершите работу. Удалите `Current\current.db`. Запустите, введите пароль.
*Ожидается:* «Файл Current\current.db отсутствует…» и кнопка **«Начать текущую базу заново…»**.
Нажмите её и подтвердите.
*Ожидается:*
- «Текущая база начата заново…»;
- после разблокировки Clipensk просит заново задать правила сбора;
- архивные записи (если были, F2) остаются в журнале.

**J3.** Вернитесь к `ClipenskTest\Data` через «Открыть хранилище из папки…».

## K. Предупреждение на Windows 10

Только если есть Windows 10 x64 (выполните там подготовку 1.2–1.4).

**K1.** Запустите `Clipensk.App.exe` на Windows 10.
*Ожидается:*
- окно с предупреждением «Clipensk поддерживает только Windows 11. На этой версии Windows (10.0.…) его
  работа не проверялась и не гарантируется. Clipensk продолжит работу.»;
- после «ОК» Clipensk запускается как обычно.

**K2.** На Windows 11 такого окна при запуске нет. Проверяется попутно в A1.

## L. Папка программы без права записи

Необязательно; нужны права администратора.

**L1.** Завершите работу Clipensk. Скопируйте папку программы в `C:\Program Files\Clipensk-test` и
запустите оттуда `Clipensk.App.exe` **без** «Запуска от имени администратора».
*Ожидается:* сообщение «Clipensk не может сохранить свои настройки: в папку программы … нельзя
записывать…», программа закрывается. После проверки удалите `C:\Program Files\Clipensk-test`.

## M. Завершение

**M1.** Трей → «Завершить работу».
*Ожидается:* иконка исчезает, процесса `Clipensk.App.exe` в Диспетчере задач нет.
