## Замечания (доработки после проверки)

**З1. Несовпадение паролей — сразу.** При создании пароля показывать, что пароль и подтверждение
различаются, во время ввода, а не после нажатия кнопки. То же — для нового пароля в «Сменить
пароль…».

**З2. Список форматов в правилах сбора.** Визуально отделить каждый формат (название и его
параметры), чтобы при прокрутке было видно, где какой формат. Сейчас список сливается.

**З3. Окно при потере фокуса.** Пока открыты правила сбора, щелчок мимо окна прячет его; при
повторном открытии из трея показывается журнал, а не правила. Кнопки окна на панели задач нет —
вернуться можно только через трей.

**З4. Последовательная первоначальная настройка.** Если правила сбора не заданы, об этом нужно ясно
сообщать при первой настройке; лучше сделать их обязательным шагом после первого запуска и так же
явно запрашивать другие ключевые параметры — последовательный мастер настройки.

**З5. Только русский язык в интерфейсе.** Во встроенных строках есть английские слова (например, на
странице журнала: «resident capture runtime использует эту policy», «Custom-binary mappings»).
Пользователь не должен разбираться в смеси языков. Проверка встроенных строк: 57 из 465 содержат
латинские слова — «Current», «Archive», «payload», «policy», «runtime», «PRAGMA», «VACUUM» и другие.

**З6. Повтор приложения в списке.** В «Приложениях» `chrome.exe — Группа по умолчанию` показан
дважды (B1).
