# Clipensk

Clipensk — Open Source Windows-приложение для долговременного журналирования буфера обмена, быстрого доступа к истории и контекстной работы с ней в зависимости от приложения-источника и приложения, из которого вызывается журнал.

## Статус проекта

Проект находится на стадии архитектурного проектирования и ранней реализации protected application lifecycle.

Основная Windows-платформа интерфейса: **WinUI 3 / Windows App SDK**.

## Основные идеи

- резидентная работа в пользовательской Windows-сессии;
- долговременная история буфера обмена;
- быстрый журнал и полнофункциональный просмотр истории;
- контекст источника данных и текущего приложения;
- зашифрованные актуальная и архивные базы;
- сегментированный архив по календарным дням;
- прозрачный поиск по актуальной и необходимым архивным базам;
- отдельное файловое хранение изображений и разрешённых пользовательских бинарных форматов;
- индивидуальные политики сбора данных для приложений;
- встроенный русский интерфейс и внешние файлы локализации;
- полностью Open Source модель распространения.
